# LearningIQ website

Open `index.html` in a browser. The hospitality and entertainment pages link to a shared, reusable `course.html` detail template.

Course information lives in `courses.js`. Add an entry with a unique ID, industry, category, title, availability status and the other data fields; the industry page displays it automatically. The current detail template intentionally shows placeholders for unconfirmed details. The two industry pages share `industry.css` and `industry.js`.

Catalogue examples are marked only where the name clearly matches the supplied catalogue examples. Concept courses are illustrative and are not confirmed live offerings. Trade learning directions on the homepage are illustrative. No durations, fees or accreditation have been supplied.
